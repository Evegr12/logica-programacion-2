# Conversor de temperaturas

Programa realizado con HTML y JavaScript que convierte una temperatura ingresada en grados Celsius a grados Fahrenheit y Kelvin.

## Funcionalidades

* Solicita una temperatura en grados Celsius mediante un input.
* Convierte la temperatura a grados Fahrenheit.
* Convierte la temperatura a grados Kelvin.
* Muestra los resultados en el DOM.
* Muestra un mensaje de error cuando el campo está vacío.
* Permite ingresar temperaturas positivas, negativas y decimales.

## Fórmulas utilizadas

* Fahrenheit: `(Celsius × 9 / 5) + 32`
* Kelvin: `Celsius + 273.15`

## Tecnologías

* HTML5
* JavaScript

## Cómo utilizarlo

1. Abre el archivo `index.html` en el navegador.
2. Ingresa una temperatura en grados Celsius.
3. Presiona el botón **Convertir**.
4. Observa los resultados en Fahrenheit y Kelvin.

## Ejemplos

| Celsius | Fahrenheit | Kelvin |
| ------: | ---------: | -----: |
|      45 |        113 | 318.15 |
|      14 |       57.2 | 287.15 |
|     -10 |         14 | 263.15 |
